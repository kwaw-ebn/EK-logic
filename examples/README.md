# Synthetic example data

`public_health_demo.csv` is entirely invented for demonstrations and tests. It is not Ghana Health Service performance data, contains no patient data, and must never be described as actual district results. Upload it manually; it is not loaded into your account automatically.

Example analysis: group by district, sum visits. Expect Agona East = 201 and Winneba = 167. Group by date and use a line chart to view the synthetic monthly counts. A mean of visit rows is not an average per patient.
